## 🚀 使用示例

### 当前支持的LESS功能

```less
// 变量和运算
@base-color: #333;
@margin: 10px;

// 颜色函数（新增！）
.theme {
    color: @base-color;                    // #333
    background: lighten(@base-color, 20%); // #666
    border: darken(@base-color, 10%);      // #1a1a1a
}

// 嵌套和父选择器
.navbar {
    padding: @margin;
    
    &:hover {
        background: lighten(@base-color, 30%);
    }
    
    .nav-item {
        margin: @margin / 2;
    }
}

// 媒体查询嵌套
.responsive {
    width: 100%;
    
    @media (max-width: 768px) {
        width: percentage(0.5);
    }
}

// 数学函数
.math-demo {
    width: round(10.6px);    // 11px
    height: ceil(5.2px);     // 6px
    opacity: percentage(0.5); // 50%
}
```
